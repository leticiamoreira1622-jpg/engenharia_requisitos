## Atividade prática
### Quem utilizará o sistema?
O sistema de controle de alunos será utilizado os funcionários da escola e os responsáveis legais dos alunos.
### Cite 3 requisitos funcionais (o que o sistema deve fazer)
Requisitos funcionais - armazenar os dados pessoais do aluno, registrar entrada e saída dos alunos, comunicar os responsáveis sobre a performance e movimentação do aluno. 
### Cite 2 requisitos não funcionais (como o sistema deve funcionar)
Requisitos não funcionais - definição de níveis de prioridade diferentes para contas com cargos diferentes, envio de notificações para os responsáveis do aluno sobre diversos registros. 
### Explique, em poucas palavras, por que é importante levantar os requisitos antes de desenvolver um software.
A importância de levantamento de requisitos é a clarificação do que o cliente almeja, evitando o retrabalho posterior e corte de gastos.
